──────────────────────────────────────────────────────────────────────────
第1回            第1〜2回           第3〜5回           第2回/第3回      第4〜6回
                                                       （2つの山）      （常時）

### KGI
6ヶ月で **ガジェタッチ経由の売上を可視化し、単発ではなく「継続的に売れる導線」を1本つくる**。

### KPI（各回で必ず取る5指標）

| 指標 | 取り方 | 目安（1回あたり） |
|------|--------|------------------|
| ① コーナー同時接続 | 配信アナリティクスのピーク | 300〜 |
| ② 専用クーポン利用数 | Shopifyクーポンコード（回ごとに別コード） | 回により設定 |
| ③ 専用URLのセッション | UTM付き短縮URL（回ごとに別URL） | 回により設定 |
| ④ WSC新規登録・投稿数 | `campaigns` slug 単位で集計（§5） | 回により設定 |
| ⑤ SNS二次投稿数 | 指定ハッシュタグの投稿数 | 第4回以降が本番 |

**重要**: ②③は回ごとにコード／URLを分ける。これをやらないと「どの回が効いたか」が6ヶ月後にわからなくなり、来期の継続判断ができません。ここだけは初回から仕込みます。

### 数字の考え方（皮算用ではなく設計の根拠）

同接300・6回で延べ約1,800接触。生配信は視聴者の重複が大きいため、**同じ人に6回当てる設計**と割り切ります。これは弱点ではなく強みで、単発PRでは作れない「7回接触の法則」的な積み上げが効きます。したがって6回は**バラバラの単発企画にせず、シリーズとして連続性を持たせる**のが基本方針です（§3の共通フォーマット）。

## 3. 5分コーナーの共通フォーマット

毎回ゼロから作ると、制作もガジェタッチさん側の進行も破綻します。**器を固定して中身だけ差し替える**方式にします。視聴者にとっても「またあのコーナーだ」という認識が育ちます。

### 秒割り（300秒）

| 区間 | 秒 | 内容 | 誰が |
|------|-----|------|------|
| A. アイキャッチ | 0:00–0:15 | コーナー名コール＋固定BGM／テロップ | ガジェタッチ |
| B. 今日のお題 | 0:15–0:45 | 「今日は◯◯を試します」の1行 | ガジェタッチ |
| C. 実演・本編 | 0:45–3:30 | 現物を映す。ここが主戦場（165秒） | ガジェタッチ（＋ゲスト） |
| D. 視聴者アクション | 3:30–4:30 | クーポン／URL／WSC投稿の案内。**コメント欄に固定** | ガジェタッチ |
| E. 次回予告 | 4:30–5:00 | 次回テーマを1行で予告（連続性の担保） | ガジェタッチ |

### 固定ルール
1. **165秒の本編は「1回1メッセージ」**。詰め込むと何も残りません。各回の「持ち帰ってほしい1行」を§4で1つずつ定義しています。
2. **Dは必ず入れる**。ここを削ると認知だけで終わり、購入につながりません。
3. **Eの次回予告で6回を1本の線にする**。単発6本ではなくシリーズにするための最重要パーツです。
4. **手元と装着の両方を映す**。バンドは「腕に乗ったときの印象」が商品価値そのものです。
5. **色は3色以上を並べる**。1色だけだと「バンド1本の紹介」に見え、ブランドとして認知されません。

### 第1回：「なぜこのブランドを作ったのか」— 菅原社長 生出演

- **時期**: 8月下旬（値上げ日の2〜3週間前）
- **目的**: 認知と信頼の獲得。「知らないブランド」から「人の顔が見えるブランド」へ
- **持ち帰ってほしい1行**: **「Apple Watch のバンドを本気で作っている日本のブランドがある」**
- **出演**: ガジェタッチ／菅原社長（生出演）

#### 構成（300秒）

| 秒 | 内容 |
|-----|------|
| 0:00–0:15 | コーナー始動のアイキャッチ。「今日から半年、Apple Watchのバンドを掘っていきます」 |
| 0:15–0:45 | 菅原社長を紹介。**肩書きより先に「この人がこのバンドを作った人」**として出す |
| 0:45–1:45 | ブランドの成り立ち。「なぜ Apple Watch のバンドだったのか」を社長の言葉で（60秒） |
| 1:45–3:00 | 現物。代表的な3ラインを実物で（FKM／レザー／**チタン**）。素材と作りの違いを触りながら（75秒） |
| 3:00–3:30 | **チタンバンドに寄せる**。「これ、来月から値上げになるんですよね？」をガジェタッチさんから聞いてもらう形にする（30秒） |
| 3:30–4:30 | 視聴者アクション：配信限定クーポン `GT01` ＋ 専用URL。Watch Style Club の紹介（20秒だけ） |
| 4:30–5:00 | 次回予告「来週のApple発表を受けて、今持ってるWatchをどうするか話します」 |

#### 設計意図
- **値上げの告知を社長本人の口から言わせない**。ガジェタッチさんが質問し、社長が答える形にすると「宣伝」ではなく「情報」になります。生配信の視聴者はここに敏感です。
- 1回目に商品を売り込みすぎると6回もちません。**1回目は人と思想、商品は3分の1**の配分にしています。
- WSCの紹介は20秒に留める。初回で導線を2本（購入・コミュニティ）出すと両方薄まるため、**初回は購入に一本化**し、WSCは名前だけ置きます。

#### 菅原社長への事前ヒアリング項目（台本作成用）
生配信で刺さる話は、事前に引き出しておかないと本番で出ません。以下を事前に伺って、ガジェタッチさんに質問リストとして渡します。

1. Apple Watch のバンドを作ろうと決めた瞬間の具体的なエピソード（年・場所・きっかけ）
2. 最初の試作で失敗したこと／捨てた案
3. 素材選定で譲らなかった点（特にチタン／FKM）
4. 「他社と何が違うか」を、スペックではなく体験の言葉で1つ
5. 今回の値上げの理由（原材料／為替／製法）— **誠実に説明できる形で**
6. ユーザーに一番言われて嬉しかった感想

### 第2回：「Apple発表を受けて、今のWatchをどうするか」

- **時期**: 9月上旬（Apple発表の直後、**発表から3日以内**）
- **目的**: 買い替え検討層の受け皿 ＋ **値上げ前ラストコール**
- **持ち帰ってほしい1行**: **「買い替えなくても、バンドで新しくできる」**
- **出演**: ガジェタッチ（社長はコメント出演またはVTRでも可）

#### 構成（300秒）

| 秒 | 内容 |
|-----|------|
| 0:00–0:15 | アイキャッチ |
| 0:15–0:45 | 「新型が出ましたね。でも今日は "買い替えない人" の話です」— **逆張りの入り**で耳を掴む |
| 0:45–2:00 | 手持ちのSeries 8／9／Ultra など旧モデルに Campagne を装着。**同じ本体が別物に見える**ビフォーアフター（75秒） |
| 2:00–3:00 | 新型を買う人向け：新型のケース色に合う Campagne の色を先出し提案（60秒） |
| 3:00–3:30 | **値上げラストコール**。「チタンは◯月◯日から価格改定。今の価格で買えるのは今週まで」 |
| 3:30–4:30 | 視聴者アクション：クーポン `GT02`／専用URL。**在庫と締切を明示** |
| 4:30–5:00 | 次回予告「新型が届いたら、実機に全色合わせます」 |

#### 設計意図
- Apple発表直後は**ガジェット系配信の視聴数が跳ねる週**です。ここに新規接触の最大枠を置きます。
- 「買い替えない人の話」から入ることで、**新型を買わない大多数（=旧モデル所有者）を取りこぼさない**。バンドは買い替えない人にこそ売れる商品です。
- 値上げ訴求は**この回で撃ち切る**。3回以上引っ張ると信頼を失います。

#### 第1〜2回セットの企画（打合せで「初回〜2回目で何か企画を」とあった件）
**「菅原社長への公開質問 → 第2回で本人が回答」**を提案します。

- 第1回の終盤で「社長に聞きたいこと、コメントで募集します」と告知
- 集まった質問から3つを選び、**第2回の冒頭30秒で社長が回答**（VTRまたはコメント出演）
- 狙い：①第1回のコメント欄が動く（配信の盛り上がり＝ガジェタッチさん側のメリット）②第1回と第2回が繋がる ③視聴者が「自分の質問が採用されるかも」で第2回を見に来る

制作コストがほぼゼロで、**ガジェタッチさん側にもメリットがある**のがこの案の要点です。PR企画は「PR側だけが得をする設計」だと必ず続きません。

### 第3回：「新型 Apple Watch に全色合わせてみた」

- **時期**: 9月下旬（新型発売の直後）
- **目的**: 新型購入者の**バンド同時購入**を取る
- **持ち帰ってほしい1行**: **「新型の◯◯（ケース色）には、この色」**
- **出演**: ガジェタッチ

#### 構成（300秒）

| 秒 | 内容 |
|-----|------|
| 0:00–0:15 | アイキャッチ |
| 0:15–0:45 | 「新型買いました。純正バンドのままの人、もったいないです」 |
| 0:45–3:00 | **実機に全色を順番に装着**（135秒）。ケース色 × バンド色のマトリクスを画面に出しながら |
| 3:00–3:30 | ガジェタッチさんの**個人的ベスト3**を発表（PR臭を消す最重要パート） |
| 3:30–4:30 | 視聴者アクション：クーポン `GT03`／専用URL |
| 4:30–5:00 | 次回予告「来月から、服とガジェットの相性シリーズを始めます」 |

#### 設計意図
- 新型発売直後は「本体は買った、周辺はこれから」という**財布が開いている状態**の1〜2週間です。6回のうち**最も売上が出る回**として設計します。
- 「全色合わせ」は生配信と極めて相性が良い形式です。コメントで「3番がいい」「自分は2番」と議論が起き、**滞在時間が伸びる**（ガジェタッチさん側のメリット）。
- ベスト3を**ガジェタッチさん本人の主観**で選んでもらうこと。PR案件で最も効くのは、演者が本音で1つを選ぶ瞬間です。

### 第4回：シリーズ「ガジェットとファッションの相性」第1弾

- **時期**: 10月
- **目的**: ブランドの世界観を伝える／検討層の背中を押す
- **持ち帰ってほしい1行**: **「バンドは "服" として選ぶもの」**
- **出演**: ガジェタッチ

打合せで挙がっていた「シリーズでファッションとガジェットの相性を見せる」案を、シリーズの起点としてここに置きます。

#### 構成（300秒）

| 秒 | 内容 |
|-----|------|
| 0:00–0:15 | アイキャッチ＋シリーズ名コール |
| 0:15–0:45 | 今日のお題「オフィスカジュアルに合うのはどれか」 |
| 0:45–3:00 | **同じ服・同じWatchで、バンドだけを3本替える**（135秒）。袖から覗く見え方まで映す |
| 3:00–3:30 | 結論を1つに絞る。「この服ならこれ」 |
| 3:30–4:30 | 視聴者アクション：クーポン `GT04`／**WSCへの投稿誘導をここから本格化** |
| 4:30–5:00 | 次回予告「次回、プレゼント企画やります」 |

#### シリーズ設計（第4回以降の共通テーマ軸）
「ファッション相性」をシリーズ化する場合、**シチュエーション軸**で切ると回数が作れて視聴者も自分ごと化しやすいです。

| 弾 | シチュエーション | 主役素材 |
|----|-----------------|---------|
| 第1弾（第4回） | オフィスカジュアル | レザー／チタン |

| 予備 | ジム・スポーツ | FKM |

**注意**: この軸は「ガジェタッチの視聴者層＝ガジェット好き」に対してファッション文脈が遠すぎないか、初弾（第4回）の反応で必ず検証してください。反応が鈍い場合は第6回で「スペック・耐久」寄りの軸に切り替えます（§7）。

### 第5回：SNS投稿プレゼント企画 本番

- **時期**: 11月（ギフトシーズンの入り口）
- **目的**: 拡散と、WSCへのユーザー獲得
- **持ち帰ってほしい1行**: **「投稿すれば当たる、投稿しなくても見て楽しい」**
- **出演**: ガジェタッチ

打合せで挙がっていた「リスナーへのSNS投稿を前提としたプレゼント企画」をここに置きます。**シリーズの中盤〜後半に置くのが定石**です（初回に置くと、ブランドを知らない人に投稿を求めることになり、応募が集まりません）。

#### 構成（300秒）

| 秒 | 内容 |
|-----|------|
| 0:00–0:15 | アイキャッチ |
| 0:15–1:00 | 賞品を実物で見せる（**画面で見せてから条件を言う**。順序が逆だと離脱します） |
| 1:00–2:00 | 応募方法を**3ステップで**（後述）。画面テロップ＋コメント固定 |
| 2:00–3:30 | 「こういう投稿をしてほしい」という**見本を実際に作って見せる**（90秒） |
| 3:30–4:30 | 締切・当選発表方法・注意事項。クーポン `GT05` も併走 |
| 4:30–5:00 | 次回予告「最終回、半年の総まとめと当選者発表」 |

#### 応募フロー（3ステップ厳守）

```
1. Watch Style Club に自分の Apple Watch スタイルを投稿
2. 投稿ページの共有ボタンから X にシェア（ハッシュタグ自動付与）
3. 完了（応募は自動で受付）
```

- WSC の投稿→シェア導線は**すでに実装済み**（`lib/share.ts` の共有インテント、`SHARE_HASHTAGS = #WatchStyleClub #AppleWatch`）。新規開発なしで運用できます。
- キャンペーンの応募管理も既存の `campaigns` / エントリー集計（`lib/campaign.ts`）が使えます。専用 slug を切るだけです（§5）。
- **応募条件に「フォロー」を足さない**。ステップが増えるほど応募は落ちます。3ステップが上限です。

#### 賞品設計
- **1等：チタンバンド1本**（値上げ後の価値訴求にもなる／最も見栄えがする）
- **2等：FKMバンド 3名**（当選確率を体感させる。1等だけだと「どうせ当たらない」で応募されません）
- **参加賞：WSCポイント付与**（既存のポイント／ミッション基盤で自動化可能。全員に何か返るのが継続の鍵）

- 第1回と第6回に社長を置いて**ブックエンド構造**にすることで、6回が1つの物語として閉じます。

## 5. Watch Style Club（自社基盤）との接続

このPR企画の裏側で、**ガジェタッチの視聴者を自社の資産に変換する**設計です。他社チャンネルの視聴者は借り物ですが、WSCに登録された人は自社の資産になります。ここが6ヶ月投資の本当の回収先です。

### 既存実装で足りるもの（新規開発不要）

| 用途 | 使う既存機能 | 実装状況 |
|------|-------------|---------|
| 応募受付・集計 | `campaigns` テーブル ＋ `lib/campaign.ts` のエントリー集計 | 実装済み |
| SNS拡散 | `lib/share.ts`（X/Facebook/LINE 共有インテント、OGP、共通ハッシュタグ） | 実装済み |
| 参加賞ポイント | Point Engine（`lib/points.ts`） | 実装済み |
| ミッション化 | Mission Engine（`lib/missions.ts`、`group` は汎用文字列で拡張可） | 実装済み |
| 購入者判定 | Shopify 購入証明連携（`lib/verified-purchases.ts`） | 実装済み |

### 準備が必要なもの

1. **キャンペーンレコードの作成**
   `campaigns` に slug `gadgetouch-2026` を1行追加（`supabase/seed.sql` の `opening-2026-08` と同じ形式）。第5回の応募期間を `starts_at` / `ends_at` に設定。

2. **回ごとのUTM付き着地URL**
   例：`https://watch-style-club.vercel.app/?utm_source=gadgetouch&utm_medium=live&utm_campaign=gt2026&utm_content=ep01`
   `utm_content` を回番号にしておくと、どの回から来た人が投稿・購入したかが後から追えます。**これを初回から必ず付ける**こと。

3. **Shopifyクーポンコード 6本**
   `GT01`〜`GT06`。回ごとに分けることで、回別の売上寄与が直接測れます。割引率は同一に揃え、**回による有利・不利を作らない**（比較可能性が失われるため）。

4. **ミッション定義の追加（任意）**
   Mission Engine に `group='campaign'` のミッションを追加すれば、「ガジェタッチを見て登録した人向けの導線」をアプリ内で作れます。コード変更不要でレコード追加のみ（`lib/missions.ts` の設計コメント参照）。

### 注意
`mission_definitions.visibility` の `'campaign_only'` は**判定ロジックが未実装**で、現状は安全側で非表示になります（`lib/missions.ts` の `isMissionVisible`）。第5回でキャンペーン限定ミッションを出す場合は、事前に判定実装が必要です。使わずに `'logged_in'` で運用する回避策も可能です。

## 7. リスクと対応

| リスク | 影響 | 対応 |
|--------|------|------|
| Apple Watch が発表されない／マイナーチェンジのみ | 第2・3回の前提が崩れる | 第3回を「今のWatchを買い替えずに新しくする」に差し替え。実は**バンド商材にとってはこちらの方が本質的**なので、致命傷ではない |
| 値上げ日が9月以降にずれる | 第1・2回の駆け込み訴求が空振り | ②のラストコールを③に移設。①はブランド訴求のみで成立するため影響は限定的 |
| ファッション軸が視聴者層に刺さらない | 第4回以降が滑る | 第4回の反応（コメント数・クーポン利用）で判定。鈍ければ第6回を「耐久テスト」「1年使ってどうなるか」等のガジェット文脈に切り替え |
| プレゼント企画の応募が集まらない | 第5回が不発 | 応募3ステップの厳守。加えて**参加賞を全員に**することで応募の心理的ハードルを下げる |
| 生配信で誤った価格・仕様が伝わる | 信用問題 | テロップ素材を必ず用意し、口頭情報に依存させない |
| 6回が単発の寄せ集めになる | 積み上げが効かない | 各回の「次回予告」を**必須項目として台本に明記**（§3のE区間） |
| 効果測定ができず継続判断ができない | 6ヶ月が無駄になる | 回別クーポン・回別UTMを**第1回から**。ここだけは後付け不可 |
